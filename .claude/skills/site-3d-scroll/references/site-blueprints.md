# Section blueprints by business type

These are starting structures, not templates. The *order* and the *job of each section* carry over; the visual treatment must not.

Common spine for all of them:

```
HERO (scroll-scrub video)
MARQUEE            breathing room + brand words, cheap and high-impact
STORY              who/what, with real imagery
STATEMENT          full-bleed parallax, one sentence, the emotional beat
THE THING          the core offer, with the signature interaction
PLACE / PROOF      where it happens, or why to trust it
MARQUEE            second one, usually the CTA repeated
CONVERT            the action, with the practical details beside it
FOOTER             social grid + nav + contact
```

## Restaurant / bar / hospitality

**Hero moment:** camera pushes toward a laid table, then the empty pan fills with food falling from above.

| section | job |
|---|---|
| Hero | the food, huge, moving |
| Marquee | name · cuisine · location, outline text |
| Story | "the goods arrive every morning", 3 scattered rotated photos |
| Statement | full-bleed platter, one line, ghost CTA |
| **Signature dishes** | uppercase list + prices, **image follows the cursor over the list**, tall photo on the right |
| Terrace / room | 2 cards, hover zoom |
| Marquee | "Reservations · phone number" |
| Reserve | where / hours / groups / events in a 4-cell grid, phone as the primary button |
| Footer | Instagram row + nav + contact |

Decision drivers: how much food you get, and whether there is a table at sunset. Portion size and the view are the two arguments. Reservation must be one tap away at all times.

## E-commerce / physical product

**Hero moment:** assembled product → exploded view, the Apple teardown.

| section | job |
|---|---|
| Hero | product, horizontal orientation, scroll explodes it |
| Spec band | 2-3 numbers with tiny labels, huge figure ("100% microfibre composite", "0.5mm pebble depth") |
| Material / technology | one component in isolation, dark background, macro |
| Statement | what it feels like, not what it contains |
| Configurator or variants | colour/size, ideally live |
| Detail grid | 3-4 close crops, unequal sizes |
| Buy | price, single button, shipping and returns as small print |
| Footer | |

Notes: generate hero stills at **2048** and say so in the prompt. Product bleeding off the frame edge reads more expensive than product centred with margin. If you go as far as real 3D, the add-to-cart flight path (object arcs into the cart icon) is the moment people screenshot.

## Rental / Airbnb / property

**Hero moment:** camera walks in through the door and through the space, one continuous move.

| section | job |
|---|---|
| Hero | walk-in, scroll drives the camera through rooms |
| Location line | neighbourhood, distance to the things that matter |
| Space | room by room, real photos, generous |
| Statement | the view, or the light at a specific hour |
| Amenities | plain list, no icon grid, no cards |
| Availability / book | calendar or a direct booking link |
| Host / trust | reviews, response rate |
| Footer | |

Walk-in tours are best built as **chained clips** (door → hallway → main room), each starting from the real last frame of the previous one. See hero-video.md.

## Local service (dental, salon, gym, clinic)

**Hero moment:** the space, or the transformation, not a stock person smiling.

| section | job |
|---|---|
| Hero | the room or the result |
| Trust strip | years, count, credential, one line |
| Services | list with prices, not cards |
| Statement | the outcome |
| Team | real faces, real names |
| Book | phone + form, hours |
| Footer | |

These are the highest-volume clients for this kind of work. What sells is a **before/after side by side** against their current site, not a pitch.

## SaaS / app

Be careful. This category has the strongest reflex pull (dark blue, gradient hero, three feature cards). A scroll-driven product video is the differentiator; the rest of the page should be quieter than the categories above, and the register is **product** rather than **brand**: the design serves the product instead of being the product.

## Choosing the hero moment

One sentence. If you cannot write it, it will not read on screen. Good ones share a shape: **a camera move, plus one thing changing.**

- camera walks toward the table + the pan fills
- product holds still + parts separate and float
- camera enters the door + the room reveals
- the object rotates + the surface changes colour

Bad ones: "a montage of the restaurant", "the product looking premium", "an atmospheric intro". Those have no verb.
